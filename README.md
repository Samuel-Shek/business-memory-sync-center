# 业务记忆同步中心

一个已停止维护的本地业务资料同步与审核工具。这里保存经过脱敏的现存源码，供阅读、研究和自行适配。

源码包括 macOS 应用、网页界面、后台处理、Windows 接入代码、提示词、数据格式与测试。真实资料、账号、凭据、运行记录、个人配置和旧提交历史均不包含在仓库中。示例名称与标识为虚构内容。

## 默认状态

所有真实接入默认关闭。Python 和 Ruby 源模块要求同时设置隔离目录 `SYNC_CENTER_HOME` 和显式开关 `SYNC_CENTER_ENABLE_ARCHIVED_CODE=1` 才允许载入；Ruby 还要求隔离目录已经存在。这两个变量只用于你自行适配后的隔离环境，不会补齐服务配置或账号权限。示例配置的 `retirement_active` 保持为 `true`，启动任务模板也保持禁用。

macOS 应用用 `SYNC_CENTER_HOME` 指定资料目录。未配置治理文件时只显示已停用状态，不启动后台同步。旧路径占位符会映射到隔离目录，实际接入需自行提供配置与授权。

## 查看与验证

需要 Python 3.12 或更新版本。运行 `python3 tests/test_archive.py` 可检查默认停用、路径隔离及虚构资料处理。测试不连接真实账号。

macOS 安装 Xcode Command Line Tools 后，可运行 `sh scripts/build_app.sh` 编译应用外壳。构建产物位于 `build/`，不会安装应用或后台任务。

音频解码依赖 `silk-wasm`，版本和许可见 `vendor/wechat-media/package-lock.json`。仓库不携带第三方运行二进制；若要研究该接入，可在自行建立的环境中安装依赖。

## 使用边界

这是一份源码归档，不是经过生产环境验收的安装包。原系统依赖本机治理服务、消息平台、邮件账号和其他工具；这些私有服务与凭据未发布，旧测试中需要它们的部分不能直接运行。脱敏后的真实账号接入未验证。

现存源码不能重建所有旧二进制：邮件会话辅助程序 `dws-mail-session-helper` 未找到对应源文件，已排除；未假装提供等价实现。部署清单、签名与历史运行证明也不作为源码发布。

本项目没有新增开源许可证。公开可见不代表额外授予修改、再分发或商业使用权。第三方依赖保留各自许可，详见 `NOTICE.md`。

## 公开范围

保留应用与通用后台源码、界面、通用测试、格式定义和提示词。嵌在程序里的专属客户路由已改为 `routing-rules.json` 配置，示例见 `routing-rules.example.json`。没有规则时明确拒绝自动归类。

未公开的内容包括一次性业务迁移脚本、旧资料索引生成脚本、依赖真实客户资料的验收脚本、部署签名清单、原始配置、历史与缓存。这些文件含实际业务事实或仅适用于原部署；没有把它们改名后当作虚构案例发布。运行用到但未包含的外部服务会保持不可用，需要使用者自行实现和配置。

Ruby 校验器不再内置原部署的记录编号基线，默认空集合。需要附加基线检查时，由使用者用 `SYNC_CENTER_BASELINE_IDS_JSON` 提供 JSON 字符串数组；Windows 共享目录可用 `SYNC_CENTER_WINDOWS_SHARE` 指定，默认位于隔离根内。
